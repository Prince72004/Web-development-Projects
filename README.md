🧮 Calculator App

A simple and responsive calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean user interface.

✨ Features
Addition, Subtraction, Multiplication, and Division
Clear (C) button
Delete (⌫) last entered character
Decimal number support
Error handling for invalid expressions
Responsive and modern UI design
🛠️ Tech Stack
HTML
CSS
JavaScript
📂 Project Structure
calculator/
├── index.html
├── style.css
└── script.js
🚀 How to Run
Clone the repository:
git clone https://github.com/your-username/calculator.git
Open the project folder.
Double-click index.html or run it using Live Server.
